# Photos for each business

Drop a photo into a business's folder with the exact file name shown below and it appears on the
site automatically: on the business page, its tiles, the home page and the Service Center. Until
then, that spot shows a placeholder. While you run the site locally (`npm run dev`), each
placeholder shows the file name it is waiting for.

- Any of `.jpg`, `.jpeg`, `.png`, `.webp` or `.avif` works; the name before the extension is what counts.
- Landscape photos work best. Aim for about 1600 px wide and under 500 KB (ask Claude to optimise them).
- A photo you add replaces the current photo in that spot, if there is one.
